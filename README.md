IZ Converter Installation Instructions

1. Download the "IZConverterSetup(6.4).exe" file from this repository.
2. Double-click the downloaded .exe file to run the installer.
3. If prompted by Windows Defender SmartScreen, click "More info" and then "Run anyway" (since the application might not be digitally signed yet).
4. Follow the on-screen instructions in the setup wizard to complete the installation.
5. Once installed, you can launch IZ Converter from the Start Menu or Desktop shortcut.

Requirements:
- Windows OS (Windows 10/11 recommended)

For any issues, please contact the development team at Izzi developers inc.
